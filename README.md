# LOST-AND-FOUND
F.I.N.D.
Fast Item Notification Directory - College Lost and Found Management System
Project Overview

F.I.N.D. (Fast Item Notification Directory) is a Project Based Learning (PBL) project focused on developing a desktop-based solution to manage lost and found items on a college campus.

The project aims to provide an organized and efficient way for students and staff to report lost items, register found items, and quickly check whether a lost item has already been handed in, by applying programming, Data Structures, and Object-Oriented Programming concepts along with a graphical user interface built using the Qt framework.

Objectives
To develop an efficient system for managing lost and found item records on a college campus.
To provide students with a fast way to search whether their lost item has already been handed in.
To prioritize high-value items (ID cards, wallets, phones, laptops) using a priority queue.
To maintain an ordered queue of pending lost reports so they can be processed one by one.
To apply Data Structures (hashing, queues, priority queues, sorting) and Object-Oriented Programming concepts.
To build a simple and easy-to-use graphical interface using the Qt framework.
To develop the project collaboratively using GitHub.
